# ひだまり農園 VR

トマト・いちご・スイカを手で触れて育てる農業体験VRです。`index.html` 1ファイルで動きます（Three.js を CDN から読み込み）。

- **Meta Quest**：ブラウザで開いて「VRで遊ぶ」。トリガーで作業、グリップで実をつかんで出荷箱に投げ入れ、左手首にメニュー
- **iPad**：左下スティックで移動、ドラッグで見回し、タップで作業（じょうろは長押し）
- **PC**：WASD で移動、ドラッグで見回し、クリックで作業、1〜4 で道具、F で早送り

WebXR は https が必要なので、GitHub Pages などで公開して Quest から開いてください。

## 遊びの流れ
種まき → 水やり → 花を揺らして受粉 → わき芽かき → 収穫・出荷 → 依頼達成で評判★アップ。★15 で「村一番の農園」になり、夏祭りの花火が上がります。
実が色づく時期に水を控えるとトマトが甘くなるなど、本物の栽培のコツをゲームに入れています。
